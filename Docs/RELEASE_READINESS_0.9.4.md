# OKVideoMac 0.9.4（Build 208）发布就绪记录

本轮以 v0.9.3（Build 204）为公开基线。变更包括音量拖动、字幕及内置音轨切换，以及用户授权后的崩溃诊断。见[发布说明](RELEASE_NOTES_0.9.4.md)。

Build 207 的本地候选已通过用户的同片源音量拖动、字幕和内置音轨切换复验。Build 208 递增版本并补充认证请求头脱敏测试。正式发布沿用干净 main 构建、Developer ID、Apple 公证、staple、安装与 GitHub 资产核验。见[DMG 发布流程](DMG_RELEASE_PROCESS.md)和[对应源码流程](SOURCE_RELEASE_PROCESS.md)。
