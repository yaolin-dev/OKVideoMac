# OKVideoMac 0.8.1（Build 134）Release Notes

加入 Sparkle 2.10.0 自动检查、菜单手动检查与设置；默认由用户授权检查，下载和安装仍需确认。
播放、全屏、启动或模态交互期间不突然展示自动检查授权；发现更新时可从菜单与设置查看。
安装通过已有异步退出清理，和语言切换重启助手互斥；更新退出不会采用 10 秒强制放行。
保留蓝牙 CoreAudio #18383 修复。本轮不宣称 AirPods/蓝牙或人工听音验收通过。

正式更新源通过本项目 GitHub Release 提供，要求 HTTPS、签名 appcast 与解压前验证；本机测试更新源不可用于正式发布。
详见 [自动更新](AUTOMATIC_UPDATES.md)。

修复同线路后续存在重复集数时，当前集的上一集/下一集按钮和自动连播失效的问题。
相邻集唯一时正常切换；相邻集有多个资源时手动选择，自动播放不会任意挑选或跳过歧义集。
分集展示与导航使用同一完整源快照；关闭或切换会话时旧选择失效。
保留原有版本、季数、非正片过滤及蓝牙 libmpv 修复。用户已反馈蓝牙耳机测试正常；本轮未自行完成逐项真实硬件验收。
