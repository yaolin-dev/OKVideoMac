# OKVideoMac 0.9.1（Build 189）Release Notes

Build 189 修复分集乱序、技术后缀文件名未匹配剧照，以及第 12 集因画质分组无法继续的问题。按集号查找相邻集数后优先同画质；第 8→9 集和第 12→13 集不再被画质标签隔开。缺集、跨季或语言版本不同提供明确选择。排序保留原资源标识及观看进度。

Build 188 将点播改为进度条加单行左侧播放控制，直播使用一致的 36 pt 点击区及 12 pt 底部距离。音量默认折叠并支持悬停调节，质量与十秒跳转保留在设置。状态提示、恢复操作、节目卡片及面板跟随实际控制锚点；保留 Build 187 的历史恢复和进度保护。验收以本轮实际渲染、原生交互、全屏播放测试及 Release 验证记录为准。

Build 187 修复历史恢复的 Java/Dex 异常响应丢失请求归属，并区分真实源失败与协议编号冲突。源实例按配置、站点、API、扩展参数、JAR 和域名映射隔离；玩偶详情与首页均失效时最多重建该源实例一次，保留共享登录和媒体会话。失败或取消不改历史，仍要求原文件身份匹配及续播确认后才更新记录。验收以本轮本地测试和 Release 验证结果为准。

Build 186 修复 Build 185 状态提示移位后，恢复卡片、取消、重试等操作的鼠标点击失效：操作区域使用独立的全窗口浮层和真实命中边界，仍锚定原来的点播进度条或直播状态位置。新增原生鼠标点击回归，覆盖卡片不同位置、取消、失败恢复及三种窗口尺寸。本地验收结果以本轮交付记录为准，不更新公开版本资产。

Build 185 在已验证的 Build 184 历史入口修复基础上统一播放器状态提示：点播位于进度条左上方，直播原位替换控制栏状态；取消中央加载及网速浮层，画中画按钮沿用统一悬浮反馈。本轮验证记录单独保存。Build 184 是基于 Build 182 源码的本地历史入口修复版，不更新公开版本资产。详情请求入口与站点返回的影片编号分别保存，旧记录在原配置、原站点恢复并核对原影片；YpanSo 只保留不含令牌的分享和文件身份，确认原分集后可直接续播。原记录主键、播放进度及取消/失败保护保持不变。Build 184 的 111 项 Release 回归通过，包含 9 项历史入口测试，覆盖播放前刷新和后续重试。以下功能列表沿用基线版本，打包与桌面实机验证结果由本次本地交付记录单独保存。

## 播放与网盘

- 连续拖动进度条按当前原生请求确认恢复，忽略迟到结果；拖动后立即暂停或关闭仍保留已确认进度。
- 已识别的 TVBox 夸克原文件线路积累约 3 秒媒体缓冲后恢复，并提前补充缓存。3 秒是媒体时长；播放器前向 128 MiB、后向 32 MiB 额度保持有界。
- Android HTTP 中继按断开的下游连接取消旧读取；固定版本 CatPaw 源包中的夸克、UC、阿里代理下载同步取消在途分段、重试和临时文件，不取消其他仍有效的读取或转存。
- 增加有上限的快进恢复与二次缓冲诊断。其他网盘、HLS/DASH/直播不统一套用夸克原文件缓冲配置。
- 设置新增“媒体播放使用系统代理”，默认关闭，支持保留进度重新加载并显示当前路由。系统 VPN 和源内部网络仍受各自实现影响。
- Android Bridge 与宿主统一为 0.3.54（66），验证包体版本、签名身份及授权连续性。

## 历史、详情与搜索

- 按原始网盘文件、分享和来源身份恢复播放，重新获取有效参数，保留失败或取消前的进度；兼容混合文件后缀的已解码视频切集。
- 修复 TMDB 匹配在详情补全后回退的问题；演员作品搜索与首页共用结果组件、来源筛选、停止、重试和滚动加载。
- 搜索总并发及 Node、QuickJS、Android 类型上限均为 20。本地有限统计用于优先尝试较快及常用源，取消不计失败，慢源仍会被搜索。
- 首批结果使用预算，向下滚动时自动加载后续结果；没有常驻“继续加载”按钮。
- 可见海报按从上到下、从左到右优先调度，共享任务上限 6、解码线程 2，失败重试有界。

## 直播与性能

- EPG 手动刷新绕过新鲜度缓存并合并共享请求；保留覆盖重试、失败退避及旧节目单。
- 持续分批回收废弃 EPG 批次，失败、取消或重启后继续；缓存重复 XMLTV 时间戳。
- 隐藏主窗口时暂停预取与自动追加；播放敏感阶段延后自动整包 EPG 导入，减少重复详情映射和时间线驱动的界面更新。
- 播放事件使用原生唤醒通知；海报磁盘缓存预算 512 MiB，并处理低空间和可选写入失败。
- 保留全源直播画面刷新、可见频道优先、停止与重试；采用轻量播放控制图标和一致的工具栏悬浮反馈。

## 验证边界

Release 测试、固定源包、合成 HTTP 和本地播放库测试分别验证数据完整性、取消、竞态和播放流程，不代表所有第三方源或真实网络都达到相同加速比例。
最低支持系统仍为 macOS 12.0、Apple Silicon arm64；历史 macOS 12.5.1 SwiftUI 弹窗问题未据此声明解决。HDR、4K60 与长时真实网盘性能仍按实际兼容性记录。
正式签名、公证、staple、Gatekeeper、最终文件哈希和发布提交以同版本的正式验证记录为准；既有版本资产保持不可变。
