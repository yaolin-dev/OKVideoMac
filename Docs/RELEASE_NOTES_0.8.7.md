# OKVideoMac 0.8.7（Build 151）Release Notes

本地验收版本，尚未公开发布或公证。

- 滚动弹幕按每媒体秒 140 逻辑点移动，窗口放大只延长行进时间；轨道调度使用相同速度。
- 窗口缩放保留弹幕轨迹、文字缓存与暂时被裁切的轨道占用；像素倍率变化时异步替换文字图像。
- 恢复直播台标原来的显示区域与等比缩放方式。

## Build 150（历史记录）

本地验收版本，尚未公开发布或公证。

- 以已验证的 Build 149 为基准，恢复此前已打包但遗漏合入的 Build 146 直播画面优化，保留 Android 启动提示与按需悬浮文字。
- 频道画面最多三路取图，遵守源连接额度；失败提前结束，取消进程退出后才释放名额。滚动到新区域时，即使旧区域仍有一个频道可见，也会逐步让出离屏任务的位置。
- 滚动复用已校验的频道需求，批量索引完整频道身份，减少主线程重复扫描。保留旧画面与卡片位置。
- 原后台活动入口显示频道画面加载状态，详情区分可见画面、本轮处理、缓存、新获取、失败与等待；支持仅重试失败项，数值更新不传播到整页。
- 修正画面菜单刷新项丢失文字的问题，采用原生选择菜单；缩短自动更新文案并增加台标留白。
- 弹幕过滤进度抖动，按屏幕目标显示时间连续移动；文字通过有界后台队列提前生成，播放中只由显示刷新驱动位置。保持原有默认速度、清晰度及暂停、跳转语义。
- 弹幕缓存设有明确预算，隐藏播放窗口不会持续预生成文字。测试诊断回调不进入最终 Release。

## Build 149 说明（历史）

本地验收版本，尚未公开发布或公证。

## Build 148 说明（历史）

本地验收版本，尚未公开发布或公证。

- Android 点播源自动启动时，在内容区底部显示准备、启动、连接、获取影片列表的真实阶段。
- 300 毫秒内完成不显示提示；保留已缓存页面，无缓存时显示静态占位。
- 通过只读事件流观察既有启动流程，不轮询 ADB、进程或健康检查，不触发额外启动。
- 状态只刷新独立提示视图；失败就地重试或切换源，取消及旧请求不能覆盖新请求。
- 保留 Build 145 的直播预览滚动修复以及现有播放、源配置与用户数据。

## Build 145 说明（历史）

Build 145 修复快速滚动及窗口缩放时，已显示的直播画面回退成台标的问题。仅作本地验收，未公开发布或公证。

- 可见频道依据滚动容器的实际裁剪范围计算，随窗口尺寸和列数调整；不按固定张数或 AppKit 预备卡片集合调度。
- 当前可见画面独立保留，普通缓存被淘汰也不会清空已显示的同频道画面；移出可见范围后释放保留。
- 台标取消／分辨率重载与预览清理分开；换频道、换来源、关闭预览时明确清除旧画面，防止复用串图。
- 滚动立即提升可见频道的缓存读取优先级。应用失去焦点仍可恢复本地缓存，网络抓图及播放器截图仍暂停。
- 保留有限轮次刷新、主播放优先、来源隔离及既有节目表行为。

## Build 144 的说明（历史记录）

Build 144 是直播频道画面缓存与刷新改进的本地候选，未公开发布或公证。

- 打开直播页先显示上次缓存，只自动补缺图；旧图在超过五分钟、节目切换或刷新失败时仍保留，新图成功后再替换。
- “频道显示”菜单新增“刷新频道画面”，按当前筛选列表执行一轮；重复点击合并。默认关闭循环刷新，可选每十分钟更新可见频道。
- 可见缺图优先，其次可见旧图、附近和屏幕外频道。滚动调整队列顺序，已开始且仍有效的取图可完成保存。
- 慢频道有独立的有限重试预算和备用线路机会；取图继承来源请求头和适用的网络策略，保持单并发及主播放优先。
- 缓存按稳定频道身份复用，磁盘按容量和最近使用淘汰；保留原频道列表、节目表、收藏、回看、线路选择与播放行为。

## Build 142 本地候选说明（历史）

Build 142 是 B 站播放修复的本地候选，未公开发布或公证。

- B 站流式代理区分读取超时与缓存回压，支持有界 Range 续传及同一表示的地址刷新。

- 多档画质时显示清晰度快捷入口；无选项或单档时隐藏，切换与恢复保留进度和所选画质。
- 增加会话归属校验和有限次数中途断流恢复；原有设置和详情展示保持。

## Build 141 本地候选说明（历史）

Build 141 是本地验收候选，未公开发布或公证。

- 保留本地 DASH 支持、播放重试修正和详情页效果。

## 已发布 Build 140 的说明（历史记录）

- 直播回放：支持明确声明的 M3U／TVBox／FongMi 回放模板、日期式节目表与 Native Xtream 节目归档；按节目展示进度，保留跳转、重播、下一档可回放节目和返回直播。已观察的 XMLTV 历史按来源／修订保留。可用性仍取决于服务端、有效时区、保留期和节目表覆盖，不提供任意连续时移或绕过账号边界。
- 原生画中画：视频可通过控制栏、「播放」菜单或 ⌥⌘P 进入系统小窗；共用一个 mpv 实例、上下文、字幕及音频输出。关闭或最小化主窗口后可继续播放；关闭小窗会暂停并返回。弹幕保留在主窗口。通过动态加载及签名校验使用 macOS 私有接口，接口不兼容时禁用；不适用于 Mac App Store。
- 播放信息：从「设置 → 播放信息」查看文件、原始视频参数、所选音轨和动态统计，复制时去掉 URL 凭据、查询参数及父目录。码率、下载速度和媒体／输出帧率分别标注；未知信息不推测。详情中的上次播放规格只属于当前会话和同一配置／资源／线路／集数。
- 界面与启动：统一直播、点播及回放的响应式控制栏、频道／选集、顶部节目信息和窄窗口菜单；普通启动先展示原生侧栏与海报占位，并优先恢复本地内容和主题。消除浅色标题栏的分区亮线，首屏滚动后保持连续原生背景。崩溃恢复与初始化错误门禁继续保留。
- 播放稳定性：修复同分辨率连续媒体的尺寸更新、全屏几何恢复、跳转状态和顶部布局；保留已有播放链及请求归属。
- 历史与详情：播放进度刷新不再覆盖鼠标尚未完成的单击选中；保持单击选中、双击播放以及 Cmd／Shift／键盘多选。开始播放、失败、成功及切集均保留浏览器详情页、滚动位置和独立详情请求。夸克历史重新取得当前 detail/play 凭据并核验稳定文件身份，不以旧临时 token 或同名文件自动替换。
