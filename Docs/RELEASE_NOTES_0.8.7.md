# OKVideoMac 0.8.7（Build 140）Release Notes

- 直播回放：支持明确声明的 M3U／TVBox／FongMi 回放模板、日期式节目表与 Native Xtream 节目归档；按节目展示进度，保留跳转、重播、下一档可回放节目和返回直播。已观察的 XMLTV 历史按来源／修订保留。可用性仍取决于服务端、有效时区、保留期和节目表覆盖，不提供任意连续时移或绕过账号边界。
- 原生画中画：视频可通过控制栏、「播放」菜单或 ⌥⌘P 进入系统小窗；共用一个 mpv 实例、上下文、字幕及音频输出。关闭或最小化主窗口后可继续播放；关闭小窗会暂停并返回。弹幕保留在主窗口。通过动态加载及签名校验使用 macOS 私有接口，接口不兼容时禁用；不适用于 Mac App Store。
- 播放信息：从「设置 → 播放信息」查看文件、原始视频参数、所选音轨和动态统计，复制时去掉 URL 凭据、查询参数及父目录。码率、下载速度和媒体／输出帧率分别标注；未知信息不推测。详情中的上次播放规格只属于当前会话和同一配置／资源／线路／集数。
- 界面与启动：统一直播、点播及回放的响应式控制栏、频道／选集、顶部节目信息和窄窗口菜单；普通启动先展示原生侧栏与海报占位，并优先恢复本地内容和主题。消除浅色标题栏的分区亮线，首屏滚动后保持连续原生背景。崩溃恢复与初始化错误门禁继续保留。
- 播放稳定性：修复同分辨率连续媒体的尺寸更新、全屏几何恢复、跳转状态和顶部布局；保留已有播放链及请求归属。
- 历史与详情：播放进度刷新不再覆盖鼠标尚未完成的单击选中；保持单击选中、双击播放以及 Cmd／Shift／键盘多选。开始播放、失败、成功及切集均保留浏览器详情页、滚动位置和独立详情请求。夸克历史重新取得当前 detail/play 凭据并核验稳定文件身份，不以旧临时 token 或同名文件自动替换。

本轮由 0.8.6（139）递增为 **0.8.7（140）**。Android Bridge 仍为 **0.3.48（60）**；最低 macOS 12.0、Apple Silicon arm64，固定依赖版本保持。其他 macOS 版本、显示器／HDR 场景、真实服务端与真实 Android 生命周期的历史结果保留其原范围。

正式版沿用现有 Developer ID、Hardened Runtime、Apple Accepted、公证 staple、Gatekeeper、完整源码／SBOM 和稳定更新 feed 门禁。实际验证范围和结果见[发布记录](https://github.com/yaolin-dev/OKVideoMac/blob/main/Docs/RELEASE_VALIDATION_0.8.7.md)；只有全部必要检查通过后才创建正式 Tag 和 GitHub Release。已有版本 Tag 与产物保持不可变。
