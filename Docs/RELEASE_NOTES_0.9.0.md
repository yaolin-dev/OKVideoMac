# OKVideoMac 0.9.0（Build 155）Release Notes

本轮汇总自正式 0.8.7（Build 140）之后的开源改动。最低目标仍为 macOS 12.0，支持 Apple Silicon arm64；Android Bridge 为 0.3.50（62）。

## 设置与详情

- 设置按通用、播放、影视详情、点播与搜索、直播与节目单、数据与隐私、兼容与诊断、关于与更新组织，支持按设置内容搜索。
- 点播／直播更新、兼容环境检查、缓存清理、备份与诊断导出提供进度、取消及明确结果，合并重复操作；文件与钥匙串读写移出主线程，旧请求不能覆盖切换后的数据或恢复已删除来源。
- 硬件解码设置保存后在播放器重建时恢复；配置、账号和节目单保存失败保留原有数据。
- 新增 TMDB 资料、匹配确认、演员作品与季集信息。默认使用原详情；仅在已保存有效凭据、直连开启且 API 与图片连接均就绪时，自动启用 TMDB。
- 可选择「自动（推荐）」或「始终使用原详情」。进入详情时确定布局，后台检查只影响下次进入；手动切回原详情立即生效并保留选集。原片源播放入口独立可用。
- 网络／代理变化使旧连接结论失效；检查支持取消、超时与明确反馈。关闭 TMDB 资料加载仍允许显示片源提供的公共海报。设置卡片采用紧凑下拉选择，说明与当前状态完整左对齐。

## 播放、直播与弹幕

- 增加固定 FFmpeg 构建的 DASH 支持及 libxml2 对应源码／许可证，修复相对重定向、单文件定位与失效表示回退；本地 DASH 地址通过 Android Bridge 的受限会话代理交接。
- 修复 B 站媒体流的定位与恢复：按当前资源验证 Range／实体身份，有界重试、地址刷新和回压，保留精确字节位置与原片源资源归属。
- 直播频道预览复用缓存，优先满足可见频道，最多三路独立取图并遵守来源连接额度；快速滚动、尺寸变化和普通缓存淘汰保留当前可见画面。后台活动显示真实阶段，并支持仅重试失败项。
- 弹幕按媒体时间保持速度，窗口缩放保留轨迹、字形缓存与轨道占用；提前生成有界文字缓存，显示刷新负责位置更新。
- Android 自动启动按真实准备阶段显示延迟提示；长片名、演员与筛选文字仅在被截断时补充完整提示。
- 来源及缓存分类过滤重复／空身份，避免原生分类字典断言崩溃；空分类切换清除旧分段控件，网络请求仍使用原始分类 ID。
- 崩溃报告保留事件发生时的原始版本、Build、镜像 UUID 与字段白名单，避免上传时的新版本覆盖旧报告身份。

## 验证范围与已知限制

用户已确认本轮候选在 macOS 27.0.1 实机测试正常。本机自动化及正式构建使用 macOS 14.8.9、Xcode 16.2；最终结果以[发布验证记录](RELEASE_VALIDATION_0.9.0.md)为准。真实来源、网络及服务端支持仍影响播放、TMDB 和节目单可用性。

macOS 12.5.1 历史 SwiftUI 弹窗崩溃尚缺少同系统复现与具体弹窗证据，本轮不宣称修复。第三方镜像的符号覆盖缺口继续按归档记录；用户崩溃上传授权仍由用户控制。

正式资产必须从干净 main 的准确提交通过现有 Developer ID、Hardened Runtime、Apple Accepted、staple、Gatekeeper、安装、源码／SBOM 和公开资产校验后发布。既有版本 Tag 与产物保持不可变。
