# 画中画

状态：0.8.7（Build 140）发布候选。直播、点播和直播回放共用原生画中画。

## 使用

播放视频后，点击控制栏的「画中画」按钮，或使用「播放 → 画中画」菜单及 `⌥⌘P`。
没有视频画面或系统接口不兼容时不能进入。音频文件不提供画中画。

进入后，主窗口显示「正在画中画播放」和「返回播放器」。系统小窗提供播放、暂停、
返回和关闭控制；关闭小窗会暂停播放并返回播放器，返回操作保留原来的播放／暂停状态。
关闭或最小化主窗口时，小窗继续播放；停止播放和退出 App 会清理小窗。

全屏进入画中画时，先结束系统全屏动画，再移入小窗；返回时使用普通播放器窗口。
画中画期间使用全屏操作会先返回播放器。小窗由 macOS 管理置顶、屏幕边缘停靠及调整大小。

字幕沿用 mpv 的视频合成结果，保留字幕选择、样式和时间偏移。弹幕是主窗口的独立覆盖层，
本版不会在小窗中显示；退出画中画后恢复原来的弹幕设置。同一播放实例切换影片、频道、
回放或线路时，小窗继续使用该实例；若兼容性切换必须重建播放器，会安全返回主窗口，
新画面就绪后可重新进入画中画。

## 实现与边界

通过窄 Objective-C 适配层动态加载系统 PIP.framework，逐项检查必要方法的参数签名；
不静态链接、不打包 Apple 私有框架。异常和超时会恢复主窗口，不影响普通播放入口。
这是私有接口方案，不适用于 Mac App Store；macOS 更新后仍需回归验证。

稳定的 AppKit 容器保留原来的 MPVOpenGLView。小窗和主窗口共用同一个 mpv 实例、
OpenGL 上下文、网络请求和音频输出，不进行屏幕采集、二次编码或额外解码。
系统小窗的内容窗口可见性与真实小窗不同，仅在有有效画中画归属时放行它的绘制；
普通隐藏窗口继续使用原来的节流规则。

播放实例和播放请求分别校验归属，旧回调不能影响新影片。退出、播放器重建、渲染视图
销毁和进入失败均先取消回调，再还原视图、释放系统控制器。状态更新跟随现有播放器快照，
没有新增逐帧属性轮询。界面变更通知在下一主线程周期合并发送；状态及归属仍即时更新，
避免渲染视图销毁期间同步通知重入 SwiftUI。

## 验收范围

本机为 macOS 14.8.9 / Apple Silicon。独立原型已由用户确认真实小窗有连续画面；
CoreAudio 输出与 VideoToolbox 解码随后复测正常。早先音频启动错误是测试期间的瞬时现象，
不能据此判断整台 Mac 的音频故障。

Release 原生用例覆盖单一渲染上下文、实际小窗绘制帧、最小化、关闭主窗口后继续绘制、暂停往返、字幕选择保持、
全屏进入、同实例点播／直播／回放切换、回放节目结束以及旧播放实例回调失效。
关联的控制栏尺寸、进度交互、集数和全屏恢复回归同时运行。
新增真实 NSHostingView 销毁回归，覆盖进入画中画、返回及关闭窗口后重新创建渲染视图。
2026-10-15 修复后 Release 回归：30 项通过、0 项失败，连续三轮 SwiftUI 子树销毁验证通过；
1 项既有长 GOP 用例因缺少指定素材而跳过。

macOS 14 未提供原型中探测的额外系统进度接口，本版不承诺小窗进度条或跳转按钮。
其他 macOS 版本、Intel、多显示器断连和 HDR 屏幕切换尚未做实机验收；视频色彩处理沿用
现有播放器输出，不新增 HDR 输出能力。长 GOP 跳转素材门禁需另设指定测试素材后运行。
2026-10-15 用户已确认本机画中画显示正常，修复后未再闪退。本地验收包尚未公证或发布。
