# 播放信息

状态：0.8.7（Build 140）发布候选。数据与缓存边界如下；正式测试与发布状态见[发布就绪](../../../../Docs/RELEASE_READINESS_0.8.7.md)。

## 使用方式

从播放器「设置」第一层打开「播放信息」；窄窗口从「更多」进入设置。直播、点播与回放共用此入口。默认展示文件、视频和音频信息，展开「播放状态」查看实时统计，右上角按钮复制已知信息。

| 分组 | 字段与口径 |
| --- | --- |
| 文件 | 原始文件名、封装格式、时长；可靠的非分段文件可展示文件大小 |
| 视频 | 原始分辨率、视频编码、媒体帧率、视频码率（估算） |
| 音频 | 当前音轨编号、编码、声道、采样率、音频码率（估算）；优先采用解码参数，缺失时采用所选音轨的媒体元数据 |
| 播放状态 | 软／硬解码、输出帧率（估算）、网络下载速度、缓存时长、丢帧 |

未知参数显示「—」，不会将线路名或片名中的「4K／蓝光」当作实际规格。原始分辨率来自媒体解码参数，修改播放器显示比例不会改变它。媒体帧率和输出帧率分别展示，不将 VFR 内容承诺为固定帧率。码率使用 kb/s 或 Mb/s；下载速度使用 MB/s，两者不能混为一谈。HLS／DASH、直播以及无法确认的文件大小不显示为影片总大小；本地文件不显示网络下载速度。

复制内容保留文件基本名和技术参数，去掉 URL 凭据、父目录、查询参数和片段；不包含播放地址、请求头或 Cookie。复制内容仍可能包含用户主动打开的文件基本名。

## 详情页规格

当前会话中实际播放过的资源，可以在详情页显示「上次播放规格」及对应集名。缓存严格区分配置 ID、配置更新时间、影片、线路和集数；切换配置、线路或集数不会借用其他资源的数据。仅保留最多 100 条静态观测，不持久化播放地址，不在打开详情页时下载影片或额外探测。未播放、规格未知以及重新启动后的资源不显示该摘要。

## 生命周期与性能

数据沿现有 mpv → PlayerSnapshot → AppState 通路传递。切换媒体、停止和销毁播放器立即清除旧媒体信息，快照沿用当前播放请求所有权。静态信息在加载及关键元数据变化时更新。面板打开期间每秒读取一次动态统计；关闭面板或播放器退出时取消定时器。

mpv 只观察所需的基本类型属性，不观察整个视频／音频参数映射，避免面板关闭后由渲染循环触发重复读取。详情页观察独立的静态规格缓存，不订阅播放器逐帧状态。
