# 启动与播放器界面

状态：0.8.7（Build 140）发布候选；正式测试与发布状态见[发布就绪](../../../../Docs/RELEASE_READINESS_0.8.7.md)。

正常启动直接显示与主浏览器一致的原生侧栏、搜索框及海报占位，首屏不再使用整页“正在打开”。
内容恢复期间共用该占位；小型活动提示等待 300 毫秒后显示，离开页面即取消。恢复前不创建
业务 AppState，异常退出后的确认页、初始化错误页、文件打开队列及启动中退出门禁保留。
启动与浏览器使用相同的窗口尺寸、外观策略和原生侧栏组件；切换时移除旧视图自己的标题栏按钮。标题栏使用连续的原生材质覆盖上方区域，避免分区空隙露出页面底色；滚动内容不会穿透工具栏，背景不拦截正文点击。
浅色／深色偏好在本机缓存供下次首屏使用，数据库仍为偏好来源；旧版本首次升级会在读取原偏好后建立缓存。
本地配置、主题和缓存首页先恢复，再检查可选 Android 运行环境。此项改善首屏呈现，不宣称网络或初始化耗时已减少。

播放器常规宽度下保留选集／频道、字幕、设置、画中画和全屏五个位置，内容设置和窗口操作通过间距分组。
音轨、弹幕及播放信息在设置第一层，进入后可直接返回设置。窄窗口将选集、字幕和设置收进“更多”，
画中画和全屏保留；更窄或时间较长时播放按钮使用独立一行。普通图标 18 pt，点击区域 38 pt。
单资源隐藏上一资源／下一资源按钮；多资源保留禁用边界，避免集数切换引起位移。

直播、点播、回放使用相同控制栏。直播不显示无效进度条和跳转按钮，频道列表仅使用当前播放会话的
频道快照；切换操作复用已有播放流程，并校验来源。直播顶部显示频道与当前节目，随 EPG 节目边界更新。
点播与回放标题使用单行、统一基线和顶部留白；回放保留直接返回直播。没有节目表时省略缺失节目名称。
来源、线路等详情放入信息面板，不堆叠到标题。控制栏上下间距 8 pt；展开面板、调节音量或拖动进度时保持可见。
画中画的私有接口、播放实例与渲染归属实现不变；本次只复用原入口和状态。

同分辨率媒体连续加载时，在文件加载及播放重启边界重新读取显示宽高，防止属性未变化而让新会话的画中画入口失效。没有增加轮询，也不改动系统画中画接口或渲染归属。关闭播放器时清除该会话的画中画恢复提示。
